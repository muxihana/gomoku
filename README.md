# Gomoku

讓角色坐在對面陪你下五子棋。他會看盤、回應攻防、在你求救時給提示，也會把跨局對話與戰績留在這個瀏覽器裡。

本頁是十五路、無禁手的單檔公開版：玩家執黑先行，角色執白並由頁內自寫 AI 代走。

## 開玩三步

1. 直接開啟 index.html，或用 GitHub Pages 發布後開啟；純自寫引擎不依賴外部檔案，file:// 也能玩。
2. 按右上角「設定」，填 API 端點、金鑰、模型與角色名。
3. 視需要上傳角色卡或頭像，關閉設定後直接落子。

即使還沒設好角色，棋局與兩級電腦 AI 仍可正常使用；完成設定後角色才會開口。

## 金鑰教學

站內圖文版（拿金鑰六步、免費層確認、設定頁逐欄）在棋室大廳：`https://muxihana.github.io/chambre/guide.html`。

Google AI Studio：

1. 在 Google AI Studio 建立 API key。
2. 在設定裡按「Google AI Studio」，頁面會代填相容端點。
3. 建議模型先用 gemini-3.1-flash-lite。

OpenRouter：

1. 建立 OpenRouter 金鑰。
2. 在設定裡按「OpenRouter」代填端點，再按「撈清單」選模型，或直接手填模型名。

金鑰只存在本機瀏覽器的 localStorage。只有角色要開口或你按「撈清單」時，瀏覽器才會把請求直送你填的服務；本站沒有後端，也不經手金鑰。請勿把金鑰貼進公開文章、截圖或 issue，共用電腦用完請按「清除所有資料」。

## 共用鑰匙

本頁與棋室大廳 Chambre、其他公開棋房共用 chambre_settings_v1。在同一個網站來源下，端點、金鑰、模型、角色資料與雙方頭像會以更新時間較新的設定為準；本頁的棋力、棋局、對話與戰績仍各自保存。

## 隱私

這是全客端單檔網頁。角色卡、頭像、棋局、對話、戰績與金鑰只存於訪客自己的 localStorage；換瀏覽器、裝置或網站來源不會自動同步。可用設定裡的卡包與記憶包手動搬家。

## 已知限制

- 角色對話需要相容 OpenAI Chat Completions 格式的端點，且服務端必須允許瀏覽器跨來源請求。
- 直接開檔時棋局可玩，但部分 API 供應商可能不接受 file:// 頁面的請求；遇到時請改用 GitHub Pages。
- 頁內 AI 是輕量型態評分，不是競賽級棋力；進階難度只多看一層玩家最佳回應。
- PNG 角色卡需包含 chara tEXt 欄位；也可改用 JSON、Markdown 或純文字。
- 資料只在目前瀏覽器，換裝置前請自行匯出卡包與記憶包。
